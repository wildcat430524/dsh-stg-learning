# 存储与接入检查记录

日期：2026-10-18（Asia/Shanghai）。本记录为本次开发中的源码复核与自动化测试总结，**不是独立第三方安全审计或零风险证明**。

## 已核查

| 边界 | 实现与验证 |
| --- | --- |
| 工作区身份 | Host 从 DSH `workspaceRegistry` 按 ID 取根目录；不接受浏览器指定任意磁盘根 |
| 路径 | 拒绝绝对路径、父目录、隐藏目录、Windows ADS/设备名/尾随别名，以及越界或指向隐藏/应用目录的符号链接和 junction；公开学习文档允许根内链接，内部元数据仍禁止任何链接；每层检查 `lstat` 与 `realpath` |
| 文件 | 只读取支持的 UTF-8 文档；不自动转码，8 MiB 上限；本地图片同时核对后缀与字节签名，拒绝 SVG/HTML |
| 保存 | 已读版本 SHA-256、同进程共享串行锁、替换前再次校验、相邻临时文件写入并 flush、保留旧文件完整备份 |
| 重试 | `operationId` 与输入/基准版本绑定；prepared/committed 收据覆盖替换前后中断；相同请求不重复追加原答 |
| 状态 | 字段白名单、大小与原型污染键检查、revision 冲突、课程会话映射合并；损坏元数据保持原样，不清空学习内容 |
| 学习证据 | 作答追加，不覆盖历史、不写掌握结论；引用当前轮题目 ID；旧题/重复题/异常多题拒绝表单保存，源文仍可阅读 |
| 接入 | 使用官方 Connection 精确 Fetch 路由；真实 HTTP 检查无认证 401、外来 Origin 403，再以隔离宿主正常认证读取课程 |
| 浏览器 | 草稿与版本分别保存，保存中新增输入保留；外部冲突对照；不把隔离聊天夹具称作真实模型回复 |

测试位置：`tests/host-service.test.js`、`tests/native-bridge.test.js`、`tests/native-protocol.test.js`、`tests/workbench-model.test.js`。真实宿主另见 `NATIVE-ACCEPTANCE.md`。

## 不应夸大的保证

1. Node 文件系统没有跨进程原子的“比较后替换”。另一个程序仍可能在最后的哈希检查与 rename 之间保存；建议不要让 STG Desk、Agent 和插件同时保存同一文件。
2. 路径复核不是操作系统安全沙箱。拥有本机同等权限、能在检查与访问之间反复替换目录或链接的恶意进程，不在“相对路径校验”可完全隔离的保证内。
3. 写入前 flush 文件，不宣称所有文件系统和突然断电场景均有目录级持久性保证。备份与操作收据用于恢复，不等于完整机器备份。
4. 备份和收据暂不自动清理，长期使用会占用空间；清理前应保留必要历史。大目录扫描与聚合尚未做大规模性能验收。
5. JSON 请求长度在载入请求正文后检查，不宣称流式限流或多用户服务防拒绝服务能力；域层大小限制与宿主 owner 认证仍生效。
6. 原生 Fetch carrier 的权限检查不等于导师文件工具的访问范围；工具继续服从 DSH 自己的文件权限和审批机制。

没有检查、导出或修改真实用户模型密钥；测试只使用演示课程与新建的隔离 DSH_HOME。实际 Profile 安装及重启另行记录，不属于这些隔离测试。
