# StepsToGreat 专属学习空间（0.3.0）

## 入口与隔离

学习主页只有两个初始化入口：**新学习**、**导入已有 StepsToGreat 文件夹**；下方列出已识别的学习空间。工作台标题显示当前空间与返回主页按钮，不提供通用 DSH 工作区选择器。旧版工作区选择缓存不沿用；学习会话管理也限定在当前已识别的空间。DSH 宿主自己的全局侧边栏不被隐藏或改写。

识别只读取固定的少量文件，不递归扫描其他 DSH 工作区。要求 `我的学习/00-学习档案.md` 为安全 UTF-8 文件，并满足其一：

- `.steps2great.json` 的 `version:1`、`skill:steps2great`，支持 Skill 轻量工作区；
- `AGENTS.md` 明确标识 StepsToGreat/Steps2Great，且存在 `协议/00_导师协议.md`，支持原版完整项目。

含 `.stg-initializing` 的未完成目录不会列出。隐藏标记只能由 Host 内部读取；普通文件操作仍拒绝隐藏路径、越界链接/junction、指向隐藏或应用目录的链接及目录穿越。工作台概览只扫描 `我的学习/`、`资料/`，协议等框架文件不进入课程导航。已有文档中的安全相对链接仍可打开。

## 原生目录选择与构建

同一个 Connection 鉴权/Origin/owner 边界内增加：

| 方法 | 路由 | 行为 |
| --- | --- | --- |
| GET/HEAD | `/api/stg-learning/learning` | 返回已识别的学习空间 |
| POST | `/api/stg-learning/learning/create` | `{name,operationId}`，选择父目录、创建新子目录、初始化、登记 |
| POST | `/api/stg-learning/learning/import` | `{operationId}`，选择既有根目录、校验、登记或复用 |

两个 POST 均不接受客户端路径。绝对路径由 `directoryPickerController.pick(signal)` 返回，取消返回 `cancelled:true`，不写入或登记。选择器按服务实例串行；同一 operationId 的相同请求共享结果，冲突 payload 拒绝。最多缓存 128 条结果，仅在进程内去重，不承诺重启后保留操作回执。

新学习使用 `mkdir` 非递归独占创建子目录，已有同名目录报错、完全不接管。写入前校验内置 `skills/stg-mentor/assets/project/manifest.json` 的全部 SHA-256；框架、协议、学科包、模板、工具与多 Agent 入口完整复制，档案单独复制自空模板，不携带上游学生进度。每个目标文件使用 `wx`，目录逐段校验，无覆盖写。`.steps2great.json` 记录框架版本和清单指纹。不会创建模型会话或发送请求。

构建中保留 `.stg-initializing` 标记；完整结束后移除，才登记工作区。写入开始后即使页面断开也继续完成初始化。失败保留目录并报告路径，不递归删除；若只是登记失败且初始化完整，用户可以重新导入。若仍存在初始化标记，则需要检查保留目录后人工恢复，不自动清理或覆盖。

导入不调用初始化，不复制或覆盖任何文件。对已登记的规范化路径复用原工作区 ID；只登记成功后打开工作台。原有会话和档案均不重置。

## 能力与验证边界

创建和导入依赖桌面原生目录选择器。纯 Web 没有该能力时明确提示，不降级为接受任意浏览器输入路径。`tests/learning-spaces.test.js` 覆盖取消、目录冲突、路径/保留名、资源校验、失败保留、导入复用、链接拒绝和通用工作区隔离。隔离浏览器测试使用明确排队的假目录选择结果 + 真实文件后端；这不等同于真实系统对话框测试。

新学习只初始化结构。点击“打开导师，准备开场”才创建/恢复导师会话并插入草稿，仍由用户确认发送。不会伪造目标、水平、已通过评估或第一课。

## 0.4.0 舒适起步

“新学习”打开独立页面，仅填写文件夹名称，再由系统选择父目录。取消选择保留名称，失败保留已创建目录。完成后显示学习概览，而不是直接展示空白档案模板。目标、基础与节奏留给完整 DSH 对话；可选择自然开始或 grill-me 式分轮澄清。准备请求不等于发送，所有真实进度仍来自学习文件。

## 0.4.1 旧版内部链接兼容

支持 playground 这种“我的学习/00-学习档案.md → 根目录00_学习档案.md”、课程 junction → 同一根目录课程文件夹的布局。不搬文件、不复制档案；课程树使用真实路径去重及防循环。读写保留别名，实际保存与锁/收据/备份绑定真实文档。元数据仍不允许链接；指向其他目录的资料库链接仍拒绝，不自动扩大工作区权限。
