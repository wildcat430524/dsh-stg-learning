# Python · 列表与切片

> 这一节只看清一个列表，以及它的一段。

## 先看一个列表

把四种水果按顺序放进一个列表：

```python
fruits = ["苹果", "香蕉", "橙子", "葡萄"]
```

列表用方括号 `[]` 包住元素，元素之间用逗号分隔。它们有固定的先后顺序。

## 切片：从哪开始，到哪之前停

```python
fruits[1:3]
```

结果是 `["香蕉", "橙子"]`。

`[1:3]` 表示从索引 `1` 开始取，一直取到索引 `3` 之前。Python 的索引从 `0` 开始，而且右边的边界本身不包含在结果里。

## 索引对照

| 索引 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 元素 | 苹果 | 香蕉 | 橙子 | 葡萄 |

所以 `fruits[1:3]` 拿到的是索引 `1` 和 `2`：香蕉、橙子。索引 `3` 的葡萄不在结果里。
